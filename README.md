# Login Validado con JavaScript 🔐

Práctica de manipulación del DOM y validaciones de formulario con **JavaScript puro**. Sistema de login con validación de campos en el cliente.

**Live Demo:** [https://login-test-javascript.netlify.app](https://login-test-javascript.netlify.app)

## Características

- Validación de campos de formulario (email, password, etc.)
- Feedback visual al usuario
- Manejo de eventos del DOM
- Interfaz limpia

## Tecnologías

- JavaScript (Vanilla)
- HTML5
- CSS3
- Netlify (deploy)

## Cómo ejecutarlo localmente

1. Clona el repositorio:
```bash
git clone https://github.com/victormarkno/login-validado-javascript.git
cd login-validado-javascript
```

2. Abre `index.html` en tu navegador o usa un servidor local:
```bash
npx serve .
```
